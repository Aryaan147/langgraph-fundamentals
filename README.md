## Learning Progress

### Lesson 1 — Introduction to LangGraph

Exploring the fundamentals of LangGraph, why it is useful, and how graph-based workflows operate.

**Topics covered:**
- Understanding LangGraph and its purpose
- The need for LangGraph in building LLM workflows
- Nodes and edges
- Conditional edges and dynamic routing
- Loops and cyclic workflows

### Lesson 2 — Types of Workflows

Exploring different workflow patterns in LangGraph and implementing them through practical examples.

**Topics covered:**
- Prompt Chaining
- Routing
- Parallelization
- Orchestrator Worker
- Evaluator Optimizer

**Practical implementations:**
- [`01_bmi_calculator`](notebooks/01_bmi_calculator.ipynb) and [`02_chatbot`](notebooks/02_chatbot.ipynb) — Sequential workflows
- [`03_prompt_chaining`](notebooks/03_prompt_chaining.ipynb) — Prompt chaining
- [`04_essay_checking_workflow`](notebooks/04_essay_checking_workflow.ipynb) — Parallelization
